# Raring2go! Codex Build Pack

Start here: `AGENTS.md` -> `docs/BUILD_SPEC.md` -> `docs/BACKLOG.md`.

The pack translates Product Architecture v1.2 into an implementation-ready structure for a GitHub/Codex workflow.

Recommended first milestone: Foundation + Identity/RBAC + Franchise/Advertiser core + one complete Edition vertical slice. Do not attempt all 80+ editions until the single-territory print-and-digital workflow is proven.

## Local development

Use Node.js `22.18.0` and pnpm `11.16.0`.

```bash
pnpm install
pnpm dev
```
