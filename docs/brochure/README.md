# Fujifilm pack: which file to use

| File | Use | Share with Fujifilm? |
|---|---|---|
| `MEETING_Investor_Brochure_28pp.pdf` | Full brochure for the first meeting: options, scopes, indicative ranges, appetite questions | Yes |
| `MEETING_LeaveBehind_8pp.pdf` | Short version to leave behind | Yes |
| `MEETING_Briefing_Deck_19sl.pdf` | Slides for presenting | Yes |
| `follow-up-pack/` | Same documents with the full figures: headline ask, equity, licence and channel terms, use of funds | **Only after Fujifilm picks a path and scope** |
| `INTERNAL_NEGOTIATION_SHEET.md` | Opening positions, walk-away prompts, questions to ask | **Never** |
| `AMBER_FIELDS_HOMEWORK.md` | Working and sources for all the numbers | **Never** |
| `pilot-metrics.sql` | Read-only queries for production pilot data | Internal |
| `source/` | Editable HTML for the meeting versions (open in a browser, print to PDF) | Internal |

Meeting version: 28 pages (brochure), 8 pages (leave-behind). Remaining amber boxes: your title/background and team/advisors.
