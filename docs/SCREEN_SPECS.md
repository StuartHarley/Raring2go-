# First 15 Screen Specifications

## 1. My Today
**Primary roles:** All authenticated roles
**Purpose:** Prioritised tasks, deadlines, exceptions, AI briefing and quick actions.
**Minimum UX requirements:** role-aware actions; loading/empty/error states; audit-friendly record links; responsive approval actions; global command/search integration where relevant.
